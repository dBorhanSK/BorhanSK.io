MEOW STUDIO CLOUD EDITION
========================

این نسخه برای ورود به تلگرام از Telegram Web رسمی و QR استفاده می‌کند؛ از تو API_ID و API_HASH نمی‌خواهد.

شروع سریع:
1) پوشه را در ریشه یک GitHub repository آپلود کن.
2) فایل supabase_schema.sql را در Supabase SQL Editor اجرا کن.
3) در Render گزینه New > Blueprint را بزن و repository را وصل کن.
4) در Render مقدار DASHBOARD_PASSWORD، SUPABASE_URL و SUPABASE_SERVICE_ROLE_KEY را تنظیم کن.
5) سرویس باید روی plan استاندارد 2GB RAM و با Persistent Disk دو گیگابایتی اجرا شود.
6) URL رندر را در کامپیوتر باز کن، به صفحه «اتصال تلگرام» برو و QR را با گوشی اسکن کن.
7) در صفحه «زمان‌بندی‌ها» یک کار ارسال پیام یا کلیک بساز.

محدودیت‌ها:
- HTTP KeepAlive به‌صورت پیش‌فرض فعال است و هر ۴ دقیقه از طریق آدرس عمومی سرویس، مسیر /health را درخواست می‌کند. وضعیت آخرین پینگ در خروجی /health نمایش داده می‌شود.
- این درخواست دوره‌ای می‌تواند به فعال ماندن Free کمک کند، اما uptime دائمی را تضمین نمی‌کند. برای اجرای پیوسته و نگهداری نشست QR از پلن پولی همراه Persistent Disk استفاده کن.
- این نسخه با Playwright رابط Telegram Web را کنترل می‌کند؛ تغییرات رابط وب ممکن است selectorها را نیازمند اصلاح کند.
- وبهوک /hooks/send یک webhook عمومیِ امن برای ابزارهای بیرونی است، نه Telegram Bot API webhook.
- تست‌های آفلاین موفق‌اند، ولی ورود QR و ارسال زنده باید در حساب واقعی و یک گروه آزمایشی بررسی شود.
- از حساب و گروه‌هایی استفاده کن که اجازه اتوماسیون می‌دهند؛ محدودیت‌های تلگرام و ربات مقصد را دور نزن.
